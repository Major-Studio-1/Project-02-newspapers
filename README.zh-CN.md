# Project 02 · 三个方向速读

英文 [README](README.md) 是课程提交材料，逐项回应故事、数据、可量化内容、质性材料、传统图表和表达性可视化。

| 方向 | 核心问题 | 具体呈现 | 当前判断 |
|---|---|---|---|
| 注意力的余像 | 议题淡出，是解决了还是被遗忘？ | 议题时间线 + 报纸覆盖 + 后续行动证据 | 有研究价值；不能把报道量当作全社会注意力，也不能把消失当解决 |
| 消息在路上 | 同一消息如何在传播中变化、被质疑？ | 版本对照 + 原报扫描 + 主张核查状态 | 最适合先做扎实，已有具体小样本 |
| 事件望远镜 | 一件事怎样被连接到其他事件和议题？ | 星点概览 + 局部环形关系 + 来源入口 | 适合作为探索界面；布局和边权不等于真实历史因果或训练好的神经网络 |

建议先以第二个方向作为研究核心，以第三个方向作为探索界面。第一个方向继续作为长期问题，等覆盖校正和结果追踪更充分后再做判断。

## 本轮发现

两轮定向检索得到24个候选页面，选择9页核对相关扫描段落，记录15项主张。三个可对照的消息组分别是 Boyd 舰队消息、Peace 号扣船报道、1794年放行决议。它们支持研究“消息版本和证据状态”，尚不支持总体假新闻率或历史反事实预测。

一处 distressed / dismasted 的差异来自转写错误，并不是报纸改写消息。法令附注中“八条有七条虚假”是当时的政治指控，不能直接作为我们的失实率。对照法令汇编，放行决议的日期、适用范围及担保条件三项得到支持，但这不能证明政策执行成功。

## 草图说明

每个方向各有一张多面板的 AI 辅助数字草图，包含 PNG 和可编辑 SVG，位于 sketches。它们不是本人手绘扫描，也不是已经测量的数据图。课程要求手绘；提交前需要确认课程接受这种形式，或以你自己绘制的版本替换。
